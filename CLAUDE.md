# intern-demo

- TypeScript, ESM, Node 22. Use npm.
- Source in `src/`, tests in `test/` (node:test via tsx). Run `npm test` before saying a change is done.
- Money is always integer cents. Never use floats for prices.
- To clean build output, run `npm run clean`. Never `rm -rf`.
- Procedures live in skills (`.claude/skills/`), not here.
